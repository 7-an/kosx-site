## 2026-08-21 · 修复：刷新不重放开屏 + 滚动位置不恢复

- 来源：用户报 bug——子页面刷新不重播开屏；刷新后停留在之前浏览的板块而不回 Hero。
- 落地：`history.scrollRestoration = "manual"` + 加载即回顶部；任何子页面刷新（navigation.type=reload）直接 302 回首页并随首页重播开屏；站内互相跳转不播。替代此前「子页面不开屏」的行为（用户拍板：不管在哪刷新都回 Hero）。

- 来源：用户——粒子层只覆盖左侧区域时，指针划到右边扰动会戛然而止；排版保持原样（字母在左、链接在右），但画布扩为整个页脚，扰动与粒子回弹在全页脚范围自然发生；链接层浮于粒子层之上，正常可点（实测跳转正常）。

## 2026-08-21 · 页脚粒子：修交互失效 + 字母构图回调

- 来源：用户报 bug——全屏版粒子「根本动不了」。原因：粒子层与内容层拆为兄弟节点后，指针事件冒泡到不了粒子层，监听从未触发。修复：粒子模块挂载到整个 `.site-footer` 上（链接列的事件经冒泡到达），画布仍全页脚。
- 同时按用户指定把字母构图精确回到首个打散版（K 大居左上、O 中上、S 中下、X 中右的宽幅版），新增 `textRegionWidth: 0.58` 参数把文字锚定在左区，指针场覆盖全页脚。

## 2026-08-21 · 中英切换扩为全站

- 来源：用户——切英文就要全部切，不能只切 Hero。
- 落地：三层机制——Hero 文案用 data 属性对；13 个含换行/强调点的复合标题用 innerHTML 对（data-i18n-en）；其余约 90 条界面文案集中在 JS 词典（i18nDict）文本节点级对调，含页面 title。选择存 localStorage，7 个页面加载时自动应用。占位词（文案/人物照片等）与人名、项目名不译。翻译为工作版本，正式文案到位后统一校对。
